# -Pipelined-MIPS-32-Processor-with-Hazard-Detection
Designed a 5-stage pipelined 32-bit MIPS processor (IF–ID–EX–MEM–WB) in Verilog supporting 14 instructions. Implemented hazard detection, stalling, and forwarding (EX/MEM, MEM/WB) with branch handling. Built 32×32 register file, 1KB memory, and verified via ModelSim testbenches.
